# BFL Planning Review Pack

This repository branch is a lightweight review pack for the `Buhurt Fantasy League` planning work.

## Included

- `docs/user-stories/`
  Canonical modular user stories grouped by product area.
- `docs/project-directory-structure.md`
  A concise view of the current app structure so the stories can be reviewed against the real code layout.
- `LICENSE`
  Preserved from the base repository.

## Where To Start

1. Read `docs/user-stories/README.md`
2. Review the story files in order
3. Use `docs/project-directory-structure.md` to understand how the app is organised today

## Notes

This review branch intentionally focuses on planning documentation rather than the full application source, so story review stays easy to navigate in GitHub.
